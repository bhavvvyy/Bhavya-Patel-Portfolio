Projects

Two web apps I built and deployed, and one product design I made in Figma.

Typing Speed Battle

A typing game where you race an AI opponent. It runs fully in the browser with no backend.

Live demo ↗ Source on GitHub ↗
  • The AI opponent pauses and makes mistakes the way a real typist does.
  • Three difficulty levels and 30, 60 or 120 second rounds.
  • Live words-per-minute from a sliding 10-second window, with accuracy scored by a Longest Common Subsequence check.
  • A local leaderboard kept in order with a max-heap and saved in the browser.
  • JavaScript
  • HTML
  • CSS
  • Max-heap
  • LCS algorithm

Spend Expense Tracker

A personal finance app that shows where your money goes. Amounts are shown in rupees.

Live demo ↗ Source on GitHub ↗
  • Add an expense with a title, amount, date, category and optional note, and delete it later.
  • Seven categories: Food, Travel, Shopping, Education, Bills, Entertainment and Other.
  • A dashboard with total spending, a summary per category and the most recent expenses.
  • Flask backend with an SQLite database that sets itself up on first run.
  • Python
  • Flask
  • SQLite
  • HTML
  • CSS
  • Responsive layout

Travelly, a travel booking design

A UI/UX design for finding a destination and booking a trip, made in Figma. It follows the whole journey in four screens: search, browse, decide and confirm.

  • A left sidebar keeps Home, Explore, My Bookings and Favorites one click away on every screen.
  • The destination page puts the photo gallery, rating, price per person, highlights and Book Now together, so a visitor can decide in one view.
  • The booking screen shows dates, guests and room type, then splits the total into base price and taxes and fees before payment.
  • A blue primary colour, rounded cards and large photos keep the layout light and let the destinations lead.
  • Figma

  • UX flow
